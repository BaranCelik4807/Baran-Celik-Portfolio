# Baran Çelik Portföy

**Baran Çelik Portföy** is my personal portfolio website showcasing the web development, design, and software projects I have worked on. It was built to demonstrate my skills and provide a platform for displaying my work. 

## 🚀 Features
- Fully responsive design
- Clean and modern UI
- Showcase of my projects and skills
- Personal contact page
- Easy to navigate and explore

- JavaScript
- PHP (for dynamic content – optional)
- Bootstrap (if used – feel free to remove if not)
